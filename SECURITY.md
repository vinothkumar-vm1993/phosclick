# Security

PhosClick uses a phone-local bridge and first-time native approval. Do not expose its loopback service through a public tunnel. Never publish capability tokens, signing keys, private captures or identifying device logs.

For a suspected vulnerability, use this repository's Security reporting page if available. Otherwise open an issue with a brief non-sensitive description and request a private reporting channel; do not post exploit credentials or private media. Supported release line: Android 0.9.6 with watch 0.6.20. Security fixes depend on Android/Zepp platform support as well as this application.
