# Compatibility

Android minimum: API 31 / Android 12. Compile and target SDK: 36. The existing package identifier remains `dev.zeppcamera.poc` to preserve identity. APK version 0.9.7, versionCode 42.

Physically tested: Google Pixel 6a on Android 17/API 37, official Zepp 10.10.5-play. Other Android devices have not been comprehensively tested. Features are negotiated from the selected CameraX/Camera2 lens; high frame rates, 4K, flash/torch and zoom differ by hardware. Front-camera capabilities can differ from rear-camera capabilities. Background camera access is subject to Android and OEM policy.

Watch package version: 0.6.22/code 38. Store application ID: 1136713. Screen layout: 390×450. Runtime API minimum 3.6, target 4.0. Targets: Amazfit Active 2 NFC (Square), source IDs 10223872 and 10223873, and Amazfit Active 2 (Square), source ID 10223875. Physical validation: Indian variant/source 10223875, firmware 4.6.0.3, API 402. Other two source variants are included but unverified physically. This is not a universal Zepp package.

No iOS companion, Wear OS or Apple Watch support. No continuous watch live stream, watch video playback, or watch gallery pinch zoom. Watch video review uses a still thumbnail. An active Zepp connection and the Android companion on the same phone are required.
